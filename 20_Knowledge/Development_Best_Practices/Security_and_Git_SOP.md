# 開発の絶対ルール：セキュリティとGit運用

このプロジェクトでは、以下のルールを「絶対」として運用します。

## 1. 秘密情報の徹底管理
- **APIキーやパスワード**は、必ず `90_Secrets/` フォルダ内のファイルに保存してください。
- フォルダ内のコード（プログラム）の中に、直接パスワードを書き込まないでください。

## 2. Gitによる「こまめな保存」と「わかりやすい日報」
- 作業の区切りで必ず保存（コミット）し、「いつ、誰のどんな指示で、何を変えたか」を記録します。
- **【追加ルール】**: 保存の際、AI（私）は以下の3点を中学生でもわかる言葉で説明します。
    - **目的**: 何のために作った機能か
    - **役割**: どういう仕組みで動いているか
    - **理由**: なぜその形にしたのか

## 3. 専門用語の禁止と「翻訳」
- カタカナの専門用語をそのまま使わず、実社会の例え話に翻訳して説明します。
- **例**:
    - トークン ➔ **「専用の鍵（合言葉）」**（トークン）
    - デプロイ ➔ **「アプリを世界に公開して使えるようにする」**（デプロイ）
    - Webhook ➔ **「何かが起きたらすぐに教えてくれる呼び鈴」**（Webhook）

## 4. セキュリティチェックの実施
- 新しくファイルを追加したり変更したりした後は、秘密情報が漏れていないか必ず確認します。
- AI（私）も、返答の最後に「セキュリティチェック完了」を報告します。

## 5. 復元ポイントの活用
- もし動作がおかしくなった場合は、迷わず「正常に動いていた時の保存ポイント」まで戻ります。
- 戻る作業は AI（私）が代行しますので、指示してください。
