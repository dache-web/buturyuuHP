# 開発の絶対ルール：セキュリティとGit運用

このプロジェクトでは、以下のルールを「絶対」として運用します。

## 1. 秘密情報の徹底管理
- **APIキーやパスワード**は、必ず `90_Secrets/` フォルダ内のファイルに保存してください。
- フォルダ内のコード（プログラム）の中に、直接パスワードを書き込まないでください。

## 2. Gitによる「こまめな保存」
- 作業の区切り（一つの機能ができた、設定を変えた等）で、必ず現在の状態を保存（コミット）します。
- 保存時のメッセージには、「**いつ、誰のどんな指示で、何を変えたか**」を分かりやすく記入します。

## 3. セキュリティチェックの実施
- 新しくファイルを追加したり変更したりした後は、秘密情報が漏れていないか必ず確認します。
- AI（私）も、返答の最後に「セキュリティチェック完了」を報告します。

## 4. 復元ポイントの活用
- もし動作がおかしくなった場合は、迷わず「正常に動いていた時の保存ポイント」まで戻ります。
- 戻る作業は AI（私）が代行しますので、指示してください。
