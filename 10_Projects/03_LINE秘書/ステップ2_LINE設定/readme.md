# ステップ2：LINEの設定をしよう

このステップでは、LINEとプログラム（GAS）を繋ぐための**「カギ」**を発行します。

## 1. LINE Developers（ライン・デベロッパーズ）にログインする

[LINE Developers](https://developers.line.biz/console/) を開き、自分のLINEアカウントでログインしてください。

## 2. チャネル（Messaging API）を作る

1. 「プロバイダー」を新規作成します（例：「スケジュール管理」など）。
2. 「Messaging API」という種類のチャネルを新規作成します。
3. 必要な情報（アプリ名、アイコン、メールアドレスなど）を入力して最後まで進めてください。

## 3. チャネルアクセストークンを発行する

1. 作ったチャネルの画面で、**「Messaging API設定」**というタブを開きます。
2. 一番下にある「チャネルアクセストークン（長期）」の横にある**「発行」**ボタンを押してください。
3. 長い英数字の文字列が出てくるので、それを**コピーしてメモ**しておきましょう！

これが、プログラムが自分のLINEを動かすための大切な「カギ」になります。

## できたか確認！
- [ ] LINE Developersにログインできた。
- [ ] チャネル（Messaging API）を作成した。
- [ ] **チャネルアクセストークン**をメモした。

確認できたら、いよいよプログラムを書く「ステップ3」へ進みましょう。
