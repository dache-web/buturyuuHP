# ステップ1：表とひな形（ひながた）を作ろう

このステップでは、お客さんの情報を記録する「表」と、請求書を送るための「文章の型」を準備します。

## 1. 顧客管理用の表を作る（スプレッドシート）

Googleスプレッドシートを開いて、新しいシートを作ってください。
そして、一番上の行（1行目）に左から順番にこう書いてください：

- **A列**：日付
- **B列**：LINE ID
- **C列**：ステータス

これだけでOKです！この表に、LINEで友達追加してくれた人の情報が自動で書き込まれるようになります。

## 2. 請求書のひな形を作る（Googleドキュメント）

Googleドキュメントを開いて、新しい文書を作ってください。
内容は自由ですが、あとでプログラムから名前や金額を自動で入れるために、以下の記号を使ってください：

- お名前：`{{Name}}` 様
- ご請求金額：`{{Amount}}` 円

例：
---
**【請求書】**
`{{Name}}` 様

いつもありがとうございます。
今回のサービス料金として、`{{Amount}}` 円をご請求いたします。
---

## 3. できたか確認！
- [ ] スプレッドシートの1行目に「日付」「LINE ID」「ステータス」と書いてあるか？
- [ ] ドキュメントに `{{Name}}` と `{{Amount}}` という記号が入っているか？

確認できたら、次のステップ2へ進みましょう。
