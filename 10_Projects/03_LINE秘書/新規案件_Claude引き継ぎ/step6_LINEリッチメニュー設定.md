# Step6 LINEリッチメニュー設定

## 目的

スマホのLINE画面から、よく使う操作をボタンで呼び出せるようにします。

作るボタン:

- 今日
- 明日
- 1週間
- 日程調整
- 予定追加
- リスケ

## 事前確認

LINE Official Account Managerで以下を確認してください。

- Messaging APIが有効
- Webhook URLにMakeのWebhook URLが設定済み
- Webhook利用がON
- 応答メッセージがOFF
- あいさつメッセージは必要に応じてON/OFF

## リッチメニュー作成手順

1. LINE Official Account Managerを開きます。
2. 対象の公式アカウントを選びます。
3. 左メニューから `トークルーム管理` を開きます。
4. `リッチメニュー` を開きます。
5. `作成` を押します。
6. 表示期間を設定します。
7. メニューバーのテキストは以下にします。

```text
メニュー
```

8. デフォルト表示は `表示する` にします。
9. テンプレートは6分割のものを選びます。

## ボタン設定

各ボタンは、アクションを `テキスト` にします。

| ボタン | アクション種別 | 送信テキスト |
|---|---|---|
| 今日 | テキスト | 今日の予定 |
| 明日 | テキスト | 明日の予定 |
| 1週間 | テキスト | 1週間の予定 |
| 日程調整 | テキスト | 日程調整したい |
| 予定追加 | テキスト | 予定を追加したい |
| リスケ | テキスト | リスケしたい |

## Make側での分類

リッチメニューから送られたテキストは、通常メッセージと同じようにMakeへ届きます。

想定分類:

| 送信テキスト | OpenAI intent | GAS action |
|---|---|---|
| 今日の予定 | 確認 | getSchedule |
| 明日の予定 | 確認 | getSchedule |
| 1週間の予定 | 確認 | getSchedule |
| 日程調整したい | 調整 | getAvailableSlots |
| 予定を追加したい | 予定追加 | addManualSchedule |
| リスケしたい | リスケ | getAvailableSlots |

## 予定追加ボタンの注意

`予定を追加したい` だけでは日時とタイトルが足りません。

この場合、Make側では以下のように返信してください。

```text
追加したい予定の日時と内容を教えてください。
例: 明日の13時に会議を入れて
```

## 日程調整ボタンの注意

`日程調整したい` だけでは件名や所要時間が足りない場合があります。

最初は標準60分で候補を出してもOKです。

より丁寧にする場合:

```text
何の予定を、何分くらいで調整しますか？
例: 商談を60分で調整したい
```

## リスケボタンの注意

`リスケしたい` だけでは対象予定がわかりません。

最初は候補を出し直すだけでもOKです。

より丁寧にする場合:

```text
どの予定をリスケしますか？
次週で再調整したい場合は「次週でリスケ」と送ってください。
```

## スマホでの確認

1. 公式LINEをスマホで開きます。
2. リッチメニューが表示されるか確認します。
3. `今日` を押します。
4. 「今日の予定」がチャットに送信されるか確認します。
5. Makeが動き、予定一覧が返るか確認します。

## 失敗したときに見る場所

- LINE Official Account ManagerのWebhook設定
- MakeのWebhook受信履歴
- MakeのRouter通過履歴
- GASの `ログ` シート
- GASの `エラー履歴` シート
