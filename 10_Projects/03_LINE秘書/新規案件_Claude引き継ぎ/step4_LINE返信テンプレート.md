# Step4 LINE返信テンプレート

## 基本方針

LINE返信は、GASが返す `result.text` をそのまま送るのが基本です。

```text
{{GAS.result.text}}
```

GAS側では `sourceType` が `user` の場合、以下の前置きを付ける設計にしています。

```text
以下のメッセージを転送してお使いください。
```

## source.type別の考え方

| source.type | 返信方針 |
|---|---|
| user | 転送用の文章として返す |
| group | グループ内で直接読める文章として返す |
| room | グループと同じ扱い |

## 個人LINEでの候補提示

```text
以下のメッセージを転送してお使いください。

候補日時はこちらです。
1. 05/04(月) 09:00 - 10:00
2. 05/04(月) 10:00 - 11:00
3. 05/04(月) 11:00 - 12:00

ご都合のよい番号をお知らせください。
```

## グループLINEでの候補提示

```text
候補日時はこちらです。
1. 05/04(月) 09:00 - 10:00
2. 05/04(月) 10:00 - 11:00
3. 05/04(月) 11:00 - 12:00

ご都合のよい番号をお知らせください。
```

## 個人LINEでの確定連絡

```text
以下のメッセージを転送してお使いください。

日程が確定しました。
件名: 商談
日時: 2026/05/10 13:00 - 14:00
Zoom: https://zoom.us/j/xxxx
```

## グループLINEでの確定連絡

```text
日程が確定しました。
件名: 商談
日時: 2026/05/10 13:00 - 14:00
Zoom: https://zoom.us/j/xxxx
```

## 予定確認

```text
[今日の予定]

2026/05/02 13:00 - 2026/05/02 14:00
会議

2026/05/02 16:00 - 2026/05/02 17:00
打ち合わせ
```

## 予定追加完了

```text
予定を登録しました。
件名: 会議
日時: 2026/05/10 13:00 - 14:00
```

## 不明時

OpenAI分類が `不明` の場合、Makeから直接LINEに返します。

```text
すみません、内容をうまく判定できませんでした。
「今日の予定」「明日の13時に会議を追加」「来週で日程調整」のように送ってください。
```

## 日時不足時

予定追加や確定で日時が足りない場合。

```text
日時をもう少し詳しく教えてください。
例: 明日の13時に会議を入れて
```

## タイトル不足時

予定名が足りない場合。

```text
予定の名前を教えてください。
例: 明日の13時に会議を入れて
```

## GASエラー時

```text
処理中にエラーが発生しました。
設定を確認します。
```

Makeの実行履歴で確認するもの:

- GASレスポンスの `ok`
- GASレスポンスの `error`
- HTTPステータス
- 送信したJSON Body
