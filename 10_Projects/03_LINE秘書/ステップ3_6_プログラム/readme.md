# ステップ3〜6：プログラム（GAS）を完成させよう【究極版】

このステップでは、LINEからのメッセージを受け取って、スプレッドシートやカレンダーとやり取りをさせる「プログラム」の本体を作ります。

> [!IMPORTANT]
> このプログラムは、不具合修正と使いやすさを追求した**「究極版（完成版）」**です。以前のバージョンよりも高機能になっています。

## 1. GAS（Google Apps Script）を開く

1. Googleドライブに行き、「新規」→「その他」→「Google Apps Script」を選択してください。
2. 名前を「LINE秘書」と変えておきましょう。

## 2. 準備するもの

プログラムの中には、自分の「カギ」を入れる場所があります。以下を準備してください：

- **LINEのトークン**：ステップ2でメモしたもの。
- **スプレッドシートのID**：スプレッドシートのURLから取得。

## 3. プログラムを貼り付ける

もともと書いてあるコードを全部消して、ファイル `code.gs` の内容をまるごとコピーして貼り付けてください。

---

## 究極版の新機能（おもてなし機能）

### 1. 「今月」予約の最適化
「今月」の予定を入れようとしたとき、カレンダーの初期位置が**「たった今の時間」**になります。1日まで戻って操作する必要がなくなりました。

### 2. 月選択ショートカット
メニューから「予定を入れる」を押すと、「今月」「来月」などを選べるボタンが届きます。直感的に予約が進められます。

### 3. 対話型予約フロー
日時を選んだ後、ボットが「予定のタイトルを教えてください」と話しかけます。それに答えるだけで登録が完了します。

### 4. 堅牢な設定管理
スプレッドシートの「設定」シートからカレンダーIDを賢く読み取ります（A2セルまたはB1セルのどちらでもOK）。
