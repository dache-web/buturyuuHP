## 概要
本プロジェクトは、公募案件における「顧客体験の圧倒的向上」を実証するために開発された、次世代型AIカスタマーサポート・ボットのプロトタイプです。

従来の「一問一答」形式のFAQボットの限界を超え、お客様の意図を深く読み取り、解決まで導く**「10カテゴリー × 3分岐 × 3解決策（計130＋ノード）」**の連続対話エンジンを搭載しています。

## 核心となる3つの特徴

### 1. 「誠実」を体現した対話ロジック
AIであることをわきまえ、店舗（私共）の代表として謙虚かつ頼もしい言葉遣いを徹底。お客様の不便を認め、寄り添う「プロの接客」をプログラム化しています。

### 2. 思考プロセスの可視化（Thought Analysis）
AIが回答を導き出すまでの「思考ログ」をリアルタイムで表示。ブラックボックス化されがちなAIの判断を透明化し、ユーザーに知的な安心感を与えます。

### 3. 鉄壁のエスカレーション・フロー
AIの対応範囲を超えた場合や文脈が不明確な場合、即座に有人オペレーターへの接続を提案。お客様を「行き止まり」で迷わせない、実務に即したホスピタリティ設計です。

## 技術スタック
- **Frontend**: HTML5, Vanilla CSS3 (Premium Glassmorphism Design), JavaScript (ES6+)
- **Architecture**: State-managed Branching Logic Engine
- **Content**: Professional Hospitality Script (Yu-Logic v2.0)

## 構成
- `demo/`: プレミアムWebデモ本体
- `04_Data/`: 131パスの対話定義データ
- `03_Writer/`: LLM連携用マスタープロンプト（プロ仕様）
- `02_Planner/`: 戦略的FAQリスト
