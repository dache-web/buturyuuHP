# ステップ8：LINEと合体させて完成！

いよいよ最後の作業です。作ったプログラムを動かして、LINEの画面にボタンを表示させます。

## 1. プログラムを公開する（デプロイ）

GASの画面で、以下の操作をしてください。

1. 右上の青い「デプロイ」ボタンを押し、「新しいデプロイ」を選びます。
2. 種類の選択（歯車アイコン）で「ウェブアプリ」を選びます。
3. **「アクセスできるユーザー」を「全員」**にして、「デプロイ」を押します。
4. 途中で承認を求められたら、自分のGoogleアカウントを選んで許可してください。
5. 最後に表示される「ウェブアプリのURL」をコピーします。

## 2. LINEの設定画面にURLを貼る（Webhook）

1. [LINE Developers](https://developers.line.biz/console/) を開き、自分のチャネルを選びます。
2. **「Messaging API設定」**タブを開き、「Webhook URL」という場所に、さっきコピーしたURLを貼り付けます。
3. **「Webhookの利用」を「オン」**にします。

## 3. 使いやすいボタンを作る（リッチメニュー）

[LINE Official Account Manager](https://manager.line.biz/) にログインして、以下の手順でボタンを作ります。

1. 「ホーム」→「トークルーム管理」→「リッチメニュー」を開き、「作成」を押します。
2. テンプレートを選んで、以下のボタンを設定してください：

- **ボタン1**：「今日の予定」という文字を送る
- **ボタン2**：「明日の予定」という文字を送る
- **ボタン3**：「1週間の予定」という文字を送る
- **ボタン4**：「予定を入れる方法」を教える

## できたか確認！
- [ ] GASのデプロイURLを、LINEのWebhookに貼れたか？
- [ ] 「Webhookの利用」をオンにしたか？
- [ ] LINEの画面の下に、ボタン（リッチメニュー）が表示されているか？
