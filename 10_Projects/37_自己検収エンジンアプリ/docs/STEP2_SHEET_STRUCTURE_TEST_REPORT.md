## 2. 失敗履歴と強制方針転換の記録

### 発生した問題
- **現象**: ユーザーが新規スプレッドシートから Apps Script エディタを開き `setupSelfValidationEngine` を実行した際、現在開いている親スプレッドシート内に8シートが構築されず、別途新しいスプレッドシートが新規自動生成される現象が2回連続で発生。
- **発生回数**: 2回
- **根本原因**: コンテナバインド型GASであるにもかかわらず、`SpreadsheetApp.create('自己検収エンジン_管理シート')` による新規生成処理および `PropertiesService` によるID管理方式を採用していたため。

### 強制方針転換内容
- **旧方式（廃止）**:
  - `SpreadsheetApp.create()`
  - `PropertiesService.getScriptProperties()`
  - `SpreadsheetApp.openById()`
- **新方式（採用）**:
  - `SpreadsheetApp.getActiveSpreadsheet()`
  - 今開いている親スプレッドシートへ直接8シートを構築
  - `SpreadsheetApp.create()` の使用を完全禁止

### 再発防止策
- 回帰テストとして `SHEET-001`（現在Spreadsheet利用確認）、`SHEET-009`（新規Spreadsheet誤生成なし）、`SHEET-010`（Spreadsheet ID維持）を定義し、継続検証を実施。
