# Profit Finder Pro - 取扱説明書

本システムをご利用いただきありがとうございます。
「Profit Finder Pro」は、買取リスト（CSV）とECサイト（楽天・Yahoo）の価格をリアルタイムに比較し、利益の出る商品を瞬時に特定するダッシュボードシステムです。

---

## 1. セットアップ手順

本システムを動作させるには、お使いのPCに **Node.js** がインストールされている必要があります。

1.  **Node.jsのインストール**: [Node.js公式サイト](https://nodejs.org/) から「LTS（推奨版）」をダウンロードし、インストールしてください。
2.  **プロジェクトの準備**: お送りした `dashboard_edition` フォルダをデスクトップなどの任意の場所に展開します。
3.  **初期設定（初回のみ）**: 
    - フォルダ内でコマンドプロンプトまたはターミナルを開きます。
    - `npm install` と入力して実行してください。必要なプログラムがダウンロードされます。
4.  **起動**: 
    - `node server.js` と入力して実行します。
    - 画面に「Profit Finder Pro - Dashboard running at http://localhost:3000」と表示されれば成功です。
    - ブラウザ（Chrome等）で [http://localhost:3000](http://localhost:3000) を開いてください。

## 2. 基本的な使い方

### ① スキャン設定の入力
画面上部の設定パネルで以下の項目を入力します。
- **楽天ポイント / Yahooポイント**: 獲得予定のポイント倍率を入力してください。実質仕入価格の計算に使用されます。
- **指定買取店フィルタ**: CSV内の特定の店舗だけで利益計算したい場合、その店舗名の一部を入力します（例：「森森」「ルデヤ」など）。空欄にすると全店舗の最高値で計算します。

### ② CSVのアップロード
- 「CSVファイルを選択」ボタンから、買取店から配布されている価格表CSVを選択します。
- **注意**: CSVには「JANコード（8桁または13桁）」が含まれている必要があります。

### ③ スキャン開始
- 「スキャン開始」ボタンを押すと、楽天・Yahooから最新の価格取得が始まります。
- 通信負荷を抑えるため、1件ずつ丁寧にスキャンを行います。

## 3. 分析結果の見方

スキャン結果は、利益率（ROI）の高い順に自動で並び替えられます。

- **仕入価格**: 各ECサイトでの販売価格にポイント還元を考慮した「実質仕入価格」を表示します。
- **利益比較（詳細レポート）**: 商品をクリックすると、以下の2つの利益を比較できます。
    - **指定店舗での利益**: 設定した特定の買取店で売った場合の利益。
    - **ランキング1位での利益**: 市場全体で最高値を付けている店で売った場合の利益。
- **カラーリング**:
    - **黒文字**: 利益が出る商品。
    - **赤文字（マイナス表記）**: 赤字になる商品。

## 4. フィルタリング仕様（自動排除機能）

本システムは、高い品質の結果を提供するために以下の商品を自動的に除外します。

- **中古品の排除**: 「中古」「USED」「展示品」「訳あり」などのキーワードが含まれる商品は自動的に弾かれます（※「未開封」は新品として扱います）。
- **「販売価格」の誤認防止**: CSV内の「販売価格（高い）」を「買取価格（安い）」として誤って取得しないよう、厳格なカラム名判定を行っています。

## 5. よくあるご質問

- **Q: 何も結果が出てこない**
    - A: 利益が出る商品が見つからなかったか、CSVの形式（JANコード等）が正しくない可能性があります。
- **Q: スキャンの速度を上げたい**
    - A: サイト側のアクセス制限を回避するため、意図的に速度を制御しています。安定稼働を優先した仕様ですのでご了承ください。
