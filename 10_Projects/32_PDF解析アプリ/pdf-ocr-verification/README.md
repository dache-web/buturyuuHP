# PDF・OCR精度検証ツール

## プロジェクト概要
本プロジェクトは、PDFの読み取り精度、文字座標、表解析を検証するためのツールです。
現在、第1段階の暫定安定版（PDF direct text extraction MVP）として動作しています。

## 現在の動作範囲（PDF.js直接抽出MVP）
* **PDF表示機能**: アップロードしたPDFの表示、ページ送り、拡大・縮小、横幅に合わせる、ページ全体表示、100%表示。
* **文字抽出機能**: PDF.jsを利用した直接抽出により、PDF内のテキスト要素を取得。
* **ページごとの独立解析**: ファイル選択時に全ページをバックグラウンドで解析します。一部のページが画像であっても停止せず、次ページ以降のテキストを抽出します。
* **結果のタブ表示**: 抽出テキスト、文字要素（座標等）、生JSON形式での確認が可能。
* **データダウンロード**: 全文テキストおよび文書全体JSONのダウンロードに対応。

## 開発環境の起動方法
```bash
npm install
npm run dev
```
※開発サーバーは Webpackモード(`next dev --webpack`)で起動します。
