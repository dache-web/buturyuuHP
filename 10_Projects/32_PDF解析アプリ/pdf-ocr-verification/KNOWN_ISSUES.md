# 既知の不具合・制限事項 (Known Issues)

現在のバージョン（第1段階の暫定安定版）における既知の制限事項は以下の通りです。

## 機能制限事項
* **画像文字の抽出不可**: 画像として保存された文字は取得できません。
* **文字レイヤー必須**: PDF内部に文字レイヤーがあるPDFのみ直接抽出可能です。
* **OCR非対応**: 現在のバージョンでは、OCR機能は実装対象外です。

## 動作の不安定性
* **抽出処理の失敗**: 一部のPDFファイルにおいては、文字抽出処理全体が失敗する場合があります。
* **初回PDF表示の不安定性**: PDFを初めて表示した直後、まれに1ページ目のプレビューが白紙になるなどの不安定な挙動が発生する場合があります。
  * **回避方法**: 「次へ」や「前へ」、または「拡大/縮小」ボタンを押すなどして再描画を促すことで正常に表示されます。

## 開発環境に関する注意事項
* **Next.js開発キャッシュ破損時の対応**: Next.jsの開発キャッシュが壊れて `DOMMatrix is not defined` や `Internal Server Error` が発生する場合は、以下の手順でWebpackモードとして再起動してください。
  1. 開発サーバー（Nodeプロセス）を停止する。
  2. `.next` フォルダを完全に削除する。
  3. `npm run dev -- --webpack` （または `package.json` の `"dev": "next dev --webpack"` 設定による `npm run dev`）で再起動する。
