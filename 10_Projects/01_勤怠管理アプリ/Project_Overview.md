# 【勤怠管理】アプリ プロジェクト概要

## 目的
LINE Messaging API と Google Apps Script (GAS) を活用した、スタッフのシフト管理・過不足通知システム。
従来のチャットベースのやり取りから、モダンな Web UI への移行と、名前解決によるデータ可視化の向上を目指す。

## 主要機能
- **シフト登録**: 
  - LINE チャットからのテキスト入力（「5/15 10-18 ホール」など）
  - LINE クイックリプライによる期間指定（週、月、カスタム）
  - GAS Web App によるフォーム入力（モバイル最適化）
- **名前解決システム**: 
  - LINE UserID を表示名に自動変換。
  - `ユーザーマスタ`シートとスクリプトキャッシュによる、API制限を回避した高速な名前取得。
- **データ一元管理**:
  - `生ログ`（Webhook全受取）
  - `ログ`（解析済み操作履歴）
  - `マスタ`（最新の確定シフト）
  - 履歴ベースの管理により、後からの修正や追跡が容易。
- **自動過不足通知**:
  - `人数設定`シートに基づき、各時間帯・チームの過不足を計算。
  - 管理グループへリアルタイムに LINE 通知。

## 技術スタック
- **Backend**: Google Apps Script (GAS)
- **Frontend**: HTML5, CSS3, JavaScript (GAS Web App)
- **Messaging**: LINE Messaging API
- **Database**: Google Sheets

## 今後の展望
- 管理者向けダッシュボードの構築。
- AI（GPT-4o等）による画像からのシフト自動読み取り機能の強化。
- 打刻（出勤・退勤）機能との連携。
